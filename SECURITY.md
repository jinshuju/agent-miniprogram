# Security Policy

If you believe you have found a security issue related to Agent Miniprogram or other Jinshuju projects, please do not open a public issue.

Please contact us at support@jinshuju.net with the subject line `[Security]`, and include enough detail for our team to investigate.

Do not include API keys, secrets, access tokens, private project code, screenshots with sensitive data, or other confidential information in public issues or pull requests.
