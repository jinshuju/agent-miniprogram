# Contributing

Thanks for your interest in Agent Miniprogram.

This repository contains CLI tooling for AI-driven WeChat Mini Program automation testing. We welcome bug reports, documentation fixes, and improvements that make the tool more reliable and easier to use.

## How to contribute

- For bugs, open an issue with reproduction steps.
- For documentation fixes, open a pull request.
- For feature ideas, open an issue describing the use case first.

## Before submitting

Please make sure your contribution:

- Includes clear reproduction steps or test notes when relevant
- Does not include private project code, credentials, screenshots with sensitive data, or customer data
- Keeps CLI behavior and command names consistent with the existing README and skill reference
- Includes tests or manual verification notes for behavior changes

## Local development

```bash
npm install
npm run daemon
npm test
```
